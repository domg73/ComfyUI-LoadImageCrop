# ComfyUI-LoadImageCrop

A native custom node for ComfyUI engineered for aspect-ratio-locked, WYSIWYG image cropping directly on the official Load Image preview — drag and zoom a crop rectangle constrained to 8 fixed ratios (1:1 through 21:9) and output the exact cropped IMAGE and MASK, with paste-from-clipboard built in. What you frame on the preview is exactly what gets executed.

https://github.com/user-attachments/assets/207d909e-f521-4166-b3c7-e60b2ee0724f

> ⚠️ **Compatibility:** currently not fully compatible with ComfyUI 2.0 nodes.
